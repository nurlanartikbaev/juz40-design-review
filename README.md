# Дизайн-ревью JUZ40

Скилл для Claude сверяет дев с макетом в Figma и выдаёт текстовый отчёт о расхождениях. Фронтенд-разработчик вставляет отчёт в своего Claude и сразу исправляет их.

## Что вы получите

Отчёт в формате Markdown. В каждом пункте есть:

- критичность: «Критично», «Важно» или «Мелочь»;
- экран, ширина, адрес и ссылка на узел в Figma;
- селектор, классы и текст элемента;
- таблица CSS-значений: сейчас, нужно, токен;
- условие готовности.

Спорные пункты попадают в раздел «Уточнить у дизайнера». Claude разработчика их не исправляет.

## Что нужно

- Claude с подключённой Figma и доступом к макету
- Google Chrome
- Python 3

## Установка

**Claude Desktop.** Скачайте [dist/juz40-design-review.skill](dist/juz40-design-review.skill) и откройте файл в Claude.

**Claude Code.** Выполните две команды:

```
/plugin marketplace add nurlanartikbaev/juz40-design-review
/plugin install juz40-design-review@juz40-design-review
```

## Как запустить

Напишите Claude:

```
Проведи дизайн-ревью
```

Claude попросит 2 ссылки:

1. Макет: фрейм или секция в Figma
2. Дев: адрес страницы на стенде

Если стенд требует вход, откроется отдельное окно. Введите логин и пароль в нём и закройте окно. Не отправляйте пароли в чат.

## Как исправить расхождения

1. Отправьте отчёт фронтенд-разработчику.
2. Разработчик открывает Claude в репозитории проекта и вставляет отчёт.
3. Claude исправляет код и выводит таблицу: что исправлено, что пропущено и почему.

## Обновления

Скилл обновляется сам. Перед каждым ревью он сверяет версию с этим репозиторием, скачивает новую и работает по ней. Если GitHub недоступен, ревью идёт на установленной версии.

Новая версия хранится в `~/.juz40-design-review/current`.

## Как выпустить версию

1. Внесите правки в `skills/juz40-design-review`.
2. Выполните команду с новым номером версии:

```bash
python3 tools/release.py 2.2.0
```

3. Сделайте коммит и отправьте его в `main`.

Сотрудники получат версию при следующем ревью. Всё, что попало в `main`, сразу доходит до них, поэтому проверяйте правки до отправки.
